## 二、底部 Tab 结构（已确认 ✅）

> 结论：**首页 / 发现 / ＋发布 / 消息 / 我的**（5 Tab，中央「＋」为凸起发布按钮）。

| Tab | 角色 | 内部结构 |
|---|---|---|
| 首页 | 本地社区主阵地，**默认落地页** | 顶部「金刚区」：5 大模块 +「圈子」入口；下方社区信息流（圈子帖子 / 本地动态混排） |
| 发现 | **附近 / LBS 本地探索** | 附近的人、附近商家/服务、附近新鲜事、附近圈子；**直播入口放这里** |
| ＋ 发布 | 零门槛一级动作 | 中央凸起，一个入口两个出口：发动态（社区）/ 发信息（分类信息） |
| 消息 | 社交 IM 中心 | 两个子 Tab：「聊天」（好友私聊 + 群聊）／「通知」（交易咨询 + 系统消息） |
| 我的 | 个人中心 | 资料、我的发布、我的收藏、设置 |

**关键决策链：**
- IM 定位为**社交型**（好友 / 群聊 / 圈子），故「消息」是社交入口，且与「交易咨询」分层（聊天 / 通知两个子 Tab）。
- 首页默认落地：核心循环是「逛本地内容 → 看中一条 → 发起聊天」，聊天是转化动作不是起点。
- 直播**暂不设独立 Tab**，入口先放「发现」，跑通后升级为独立 Tab。
- 圈子**融在首页社区流**（入口在金刚区），规模起来后升级为独立 Tab。
